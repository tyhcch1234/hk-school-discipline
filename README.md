# 中學訓導工作 · 資料站

香港中學訓導工作的完整整理：法律底線、校內架構、處分層級、程序要求與欺凌處理。
純靜態網頁，零外部依賴，可直接以 GitHub Pages 發佈。

## 內容

- **定位** — 訓導 ≠ 懲罰；全校參與、訓輔合一、預防優先；1999《學生訓育工作指引》
- **法律底線** — 體罰禁令（《教育規例》第 279A 章第 58 條，1991 起）、強制舉報虐兒（第 650 章，2026-01-20 生效，25 類專業人員）、私隱、操守指引、學校行政手冊
- **架構** — 副校長／訓導主任、訓導組、班主任、輔導組、風紀、校長的分工
- **介入層級** — 全校／班級／個別三層，及與 SEN 支援的接口
- **處分階梯** — 口頭警告 → 留堂記缺點 → 小過大過 → 停課 → 開除，附批核層級
- **程序公義** — 查明事實、聽取學生、比例原則、通知家長、上訴渠道五步
- **欺凌** — 標準處理步驟、政策依據、四類欺凌（含網絡欺凌）
- **數據** — 2020/21–2024/25 共 72 宗朋輩欺凌個案，已處理 67 宗
- **六個爭議**、**10 條 FAQ**、**4 項限制**、**10 項來源**

## 技術與設計

`index.html` / `assets/style.css` / `assets/app.js`；無框架、無 CDN、無追蹤碼。
視覺：松綠 + 銅金，**平面文件風格**（無陰影、1px 細線、等寬字標籤、左側條文線），呼應「規章」主題。

## 重要說明

本頁非法律意見。處分層級屬常見做法的整理，各校校規差異很大；程序細節以校本政策、《學校行政手冊》及教育局通告為準。
